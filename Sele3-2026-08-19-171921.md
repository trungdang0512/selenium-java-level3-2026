ConfigManager --> FrameworkConfig : loads

FrameworkConfig --> ExecutionMode : chooses

BaseTest --> ConfigManager : reads config
BaseTest --> DriverManager
BaseTest <|-- LoginTest
LoginTest --> LoginPage : uses

DriverManager --> WebDriverFactory : requests driver
WebDriverFactory --> DriverProvider : delegates creation

DriverProvider <|.. LocalDriverProvider
DriverProvider <|.. RemoteDriverProvider

BasePage --> ElementActions : uses
BasePage --> BrowserActions : uses
BasePage --> UiAssertions : uses
LoginPage --> HomePage : navigates to

ElementActions --> WaitManager : waits before action
ElementActions ..> By : receives locator
ElementActions ..> WebElement : performs action

BrowserActions --> WaitManager : waits for page state

UiAssertions --> WaitManager : retries assertion

WaitManager ..> WebDriver : finds element
WaitManager ..> By : waits by locator
WaitManager ..> WebElement : returns element

TestListener --> ScreenshotService : captures on failure
ScreenshotService --> DriverManager : gets driver
